# 🧾 Smart Billing System - Windows Forms App (C# .NET Framework)

A simple and functional desktop billing system developed using **C# (.NET Framework)** and **Windows Forms**, integrated with **SQL Server**. It covers essential features for user registration, item management, billing, and invoice printing.

## 🚀 Features

- **User Login & Registration**
  - Secure login system with validation.
  - New users can sign up with details (Name, Email, Password).
  - User data stored in SQL Server.

- **Item Selection & Cart Management**
  - Add multiple items with quantity and auto calculation.
  - Dynamic cost, tax, discount, and total updates.
  - Calculate and display amount paid and change.

- **Billing & Invoice**
  - Generate invoice with total cost and payment info.
  - Preview or print the invoice.
  - Save transaction data to the database.

- **Admin Item Management**
  - Add new items to inventory.
  - Update or delete existing items.
  - View all billing records and user activities.

## 🛠️ Technologies Used

- **C# (.NET Framework)**
- **Windows Forms**
- **SQL Server (Stored Procedures & Tables)**
- **ADO.NET** for database interaction

## 🗃️ Database

- Two main tables:
  - `order_master`: stores invoice details
  - `order_details`: stores item-wise billing info
- Stored procedures for filtering by date, invoice ID, etc.
